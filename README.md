# YOLOv8 Object Detection

Place your own car.jpg beside the notebook. The first demo uses pretrained YOLOv8n weights and writes annotation.jpg. The optional webcam demo requires a desktop session and exits with q. Initial model loading may download weights.

Notebooks: [yolov8-object-detection.ipynb](yolov8-object-detection.ipynb)

From this directory, use a fresh Python 3.11 environment:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```
